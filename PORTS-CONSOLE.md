# Pesquisa de clássicos originais para navegador — 01/11/2026

O proprietário pediu apenas clássicos comerciais originais, sem homebrew ou recriações substitutas. Nenhum título novo de console foi acrescentado nesta revisão.

| Jogo | Projeto consultado | Situação para inclusão |
| --- | --- | --- |
| Gran Turismo 4 (PS2) | https://github.com/snuri00/ps2-web-recomp | O projeto recompila o jogo para WebAssembly/WebGPU, mas exige uma imagem do disco fornecida pelo usuário. Não inclui os dados do jogo. |
| God of War II (PS2) | https://github.com/snuri00/ps2-web-recomp | O autor relata menus e combate funcionando; a criação do port também depende da ISO original e da compilação local. Nenhum build nem ISO foi incluído. |
| Zelda II: The Adventure of Link (NES) | https://github.com/troyedwardsjr/z2rs | Reconstrução para desktop e navegador que exige a ROM original fornecida pelo usuário. A licença MIT é do novo código, não dos dados do jogo original. |

Fontes: READMEs oficiais dos projetos acima, consultados em 01/11/2026. Não foram baixados jogos comerciais de espelhos nem incluídos cartões que aparentem jogos prontos para jogar. As alternativas NES homebrew encontradas não foram adicionadas, seguindo a preferência do proprietário.

Para uma inclusão futura, será necessário um pacote verificável com os recursos necessários e condições de distribuição adequadas ao uso pretendido. Cada inclusão ainda passará por segurança, funcionamento e pesquisa de capa, conforme AGENTS.md.
